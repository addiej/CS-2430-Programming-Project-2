PART 1: ORDINARY SETS (bit strings) #####
Universe order (index 0 = leftmost bit): 0:a, 1:b, 2:c, 3:d, 4:e, 5:f, 6:g, 7:h, 8:i, 9:j

[SET] A (input)
    bit string : 1111100000

[SET] B (input)
    bit string : 0001111000
    elements   : {d, e, f, g}
[SET] NOT(A)
    bit string : 0000011111
    elements   : {f, g, h, i, j}
